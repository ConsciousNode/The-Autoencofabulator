Architecture v0.3: Bidirectional Masked-Byte Transformer
Forward Process: At diffusion time t ∈ (0, 1], each byte x₀[i] ∈ {0..255} is independently replaced by [MASK] (256) with probability μ(t) = 1 − α(t).
Continuous-Time NELBO Bound (bits per byte): bpb(x₀) = E_{t~U(0,1), x_t} [ (1 / (L ln 2)) · (−α'(t)/(1−α(t))) · Σ_{i : x_t[i]=[MASK]} −log p_θ(x₀[i] | x_t, t, c) ]
Bidirectional Transformer Denoiser: Token + 1D/2D (row, col) + 4×4 sub-patch slot embeddings → N× [Pre-AdaLN → RoPE Multi-Head Bidirectional Self-Attention + Local Conv → Pre-AdaLN → SiLU FFN] → Final LN → Differentiably-Gated Bilateral Context + 256-way Byte Head + 4-way Timing Helix Event Head.
